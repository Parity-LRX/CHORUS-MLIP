# Result index

Only CHORUS evidence is retained in this repository.

- `phase/` contains mechanism, rank, scope, backbone-transfer, and selected
  architecture studies.
- `external/` contains evaluations and timing records for external model
  families.
- `throughput/` contains cross-model atom-count scans and precision audits.

Directory names may preserve the as-run date and backbone label because those
fields are part of the provenance.  Transient smoke outputs, environment-build
logs, checkpoints, datasets, and manuscript render products are not part of the
curated result archive.

The former MACE-ICTC `model/`, `operator/`, `training/`, and `long_range/`
result trees were removed when CHORUS became an independent repository.
